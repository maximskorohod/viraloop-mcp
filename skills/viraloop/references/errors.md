# Коды ошибок и что делать

Формат ответа: `{error:{code,message,...}}`, `message` по-русски. Таблица кодов: `docs/API.md`.

| code | Что значит | Что делать |
|---|---|---|
| `unauthorized` | вход истёк или доступ отозван (OAuth), либо ключ неверный | Предложить переподключить Viraloop в настройках клиента (вход кодом из письма). Ключ и коды не просить в чат |
| `forbidden_scope` | доступу нет нужного права (read, edit, spend); поле `required` | Сказать, какого права не хватает: пользователь переподключает приложение и отмечает право на экране «Разрешить доступ» (или выпускает ключ с ним в кабинете) |
| `rate_limited` (429) | слишком частые чтения; поле `retry_after_s` | Подождать указанное время, опрос делать реже |
| `daily_limit_exceeded` (429) | дневной лимит кредитов токена исчерпан; поля `limit`, `spent`, `needed` | Не повторять вызов, лимит меняет только владелец в кабинете |
| `internal_error` (500) | сбой сервера | Один повтор позже, без платных действий без нового «да» |
| `not_found` | объект не существует или чужой | Перепроверить id из ответов инструментов, id не выдумывать. Вспомнить через `list_projects` |
| `too_large` | файл больше лимита | Попросить сжать или обрезать исходник |
| `too_long` | видео длиннее 5 минут | Попросить разрезать на части |
| `bad_container`, `bad_codec`, `no_video`, `no_audio`, `unreadable`, `bad_protocol`, `timeout` | файл не прошёл проверку | Попросить перекодировать в обычный MP4 (H.264 + AAC) и загрузить заново |
| `insufficient_credits` (402) | не хватает кредитов; поля `available`, `needed` | Назвать обе цифры, дать ссылку на пополнение в кабинете. Обходов нет. Ревизия при этом не создаётся |
| `idempotency_conflict` | этот ключ уже использован для другого файла или стиля | Взять новый `idempotency_key` |
| `unknown_style` | такого стиля нет; поле `supported` | Показать список `supported`, спросить |
| `revision_conflict` (409) | план изменился; поле `current_revision` | `get_plan`, показать пользователю что изменилось, повторить с новой `base_revision` |
| `cut_cache_missing` | кэш прогона потерян | Правка невозможна, нужна новая обработка. Новое согласие на кредиты |
| `bad_ops` | правка не применена | Проверить `word_ids` и форму ops по схеме инструмента `revise`, повторить один раз |
| `render_not_ready` | рендер ещё не готов, файла нет или он удалён по сроку (MP4 живёт 7 дней) | Подождать и опросить `get_job`; если истёк срок, запросить перерендер (может быть платным) |
| `preview_not_ready` | прокси для предпросмотра не готов | Подождать, позже повторить |
| `validation_error` | неверные поля; поле `fields` | Исправить названные поля |

## Коды из get_job.error_code

| error_code | Что делать |
|---|---|
| `too_large`, `too_long`, `bad_codec` | как выше, исходник надо поменять |
| `source_missing` | исходник удалён по сроку (72 часа) или потерян: загрузить заново через `create_upload` |
| `media_failed`, `processing_failed` | сбой обработки: показать русский `error`, предложить один повтор с новым ключом после «да» (кредиты возвращены) |
| `lease_expired` | воркер потерял задание: подождать, сервис перезапустит само; если статус `dead`, повторить после «да» |
